# Vistula Task Manager

Simple Task Manager built with HTML, CSS and JavaScript. Tasks are stored in Supabase (PostgreSQL) and accessed through the Supabase REST API.

- **Student ID:** 73745
- **Application:** https://vistula-team-project-73745.github.io/vistula-task-manager/
- **Repository:** https://github.com/vistula-team-project-73745/vistula-task-manager

## Features

- Display, add, edit and delete tasks
- Mark tasks as completed / incomplete
- All changes are saved in the Supabase `tasks` table
